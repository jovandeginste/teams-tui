# teams-tui

`teams-tui` is a read-only terminal UI (TUI) and CLI for browsing and querying the local SQLite message archive (`~/.local/share/teams-archive/teams.db`) generated by `teams-for-linux`.

## Why We Use This

Microsoft Teams history is slow to search and browse inside the Electron client. A custom JavaScript preload injection (`message-logger.js`) records incoming and historical messages, channels, authors, reactions, and mentions into a local SQLite database (`~/.local/share/teams-archive/teams.db`). `teams-tui` provides a fast, read-only IRC-style terminal interface and CLI export tool over that archive.

### Features

- **IRC-style TUI**:
  - Left pane lists channels/rooms ordered by most recent activity; right pane renders messages chronologically with a live 1-second auto-refresh.
  - Deterministic per-author and per-thread colors computed from the first 6 hex characters of the MD5 hash (`#rrggbb`).
  - Visual thread indicators (`┬` for thread root with bold/underlined timestamp, `│` for replies in the same thread).
  - Quoted reply blocks (`│ `), fenced code blocks (`▎ ` with `[lang]` header), and inline code spans.
  - Channel filtering (`c`), in-channel message search (`f`), and global message search across all channels (`s`).
- **`messages` CLI subcommand**:
  - Exports archived messages for a date range (defaulting to today) as a formatted terminal table (`aquasecurity/table`) or JSON.

## How We Implemented This

The project is written in Go with the CLI entrypoint in `./cmd/teams-tui/` and reusable packages in `./pkg/`:

- `cmd/teams-tui/main.go`: Cobra CLI root command (launches the interactive TUI) and `messages` subcommand.
- `pkg/archive/archive.go`: Read-only SQLite access via `gorm.io/gorm` and `github.com/glebarez/sqlite` (pure Go, `CGO_ENABLED=0`), date parsing, and `table`/`json` output writers using `github.com/aquasecurity/table`.
- `pkg/tui/tui.go`: Interactive terminal UI built with `github.com/charmbracelet/bubbletea`, `github.com/charmbracelet/lipgloss`, and `github.com/charmbracelet/x/ansi`.

## How to Build and Run

Use the `Makefile` targets:

```bash
# Build ./teams-tui binary
make build

# Install into $GOBIN / $GOPATH/bin
make install

# Run unit tests
make test

# Run golangci-lint
make lint

# Tidy and vendor dependencies
make deps
```

### Interactive TUI

```bash
# Launch TUI with default archive (~/.local/share/teams-archive/teams.db)
teams-tui

# Launch TUI pre-filtered to a channel name
teams-tui -c "General"

# Use a custom database path
teams-tui -d /path/to/teams.db
```

#### Keyboard Shortcuts (`?` in TUI)

- `↑`/`↓`, `j`/`k`, mouse wheel: Navigate channels or scroll messages in the focused pane
- `tab`, `h`/`l`, `←`/`→`, mouse click: Switch focus between the channel list and message pane
- `J`/`K`, `pgup`/`pgdn`, `ctrl+u`/`ctrl+d`: Scroll messages directly from either pane
- `home`/`end`, `g`/`G`: Jump to top or bottom
- `c` (or `/` in channel pane): Filter channels by name
- `f` (or `/` in message pane): Search messages in the current channel
- `s`: Search messages across all channels (filters both channels and messages)
- `esc`: Clear active search filter or return focus to channel list
- `?`: Toggle keyboard shortcuts overlay popup
- `q`, `ctrl+c`: Quit

### CLI Subcommand (`messages`)

```bash
# Show all messages from today as a table
teams-tui messages

# Filter by date range and channel name
teams-tui messages --from 2026-10-30 --to 2026-11-02 -c "General"

# Filter by author and content substring, output as JSON
teams-tui messages -a "Alice" -q "deploy" -o json
```
